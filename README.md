# Projetos em GNU Octave

Repositório para armazenar códigos acadêmicos e pessoais desenvolvidos em GNU Octave.

## Estrutura

- `academic/`: experimentos, exercícios e projetos acadêmicos.
- `personal/`: scripts e projetos pessoais.
- `code/`: funções e códigos reutilizáveis.
- `assets/plots/`: imagens e gráficos gerados pelos scripts.
- `assets/figures/`: outras figuras e ilustrações.
- `assets/data/`: arquivos de dados usados nos experimentos.

## Execução

Abra o GNU Octave na raiz do repositório e adicione as funções reutilizáveis ao caminho quando necessário:

```octave
addpath(genpath('code'));
```
